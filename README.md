# CRM API Project

A simple Customer Relationship Management (CRM) backend API developed using Python and Flask.

## 📌 About the Project

This project provides backend APIs for managing CRM-related data such as user registration, login, leads, and company-specific leads.

The project was developed as a backend API project using Flask and Microsoft SQL Server.

## 🚀 Features

- User Registration
- User Login
- Lead Management
- Company-wise Lead Retrieval
- REST API endpoints
- SQL Server database connectivity
- API testing using Postman
- CORS support

## 🛠️ Technologies Used

- Python
- Flask
- Flask-CORS
- Flask-SQLAlchemy
- Microsoft SQL Server
- PyODBC
- Postman
- Python-dotenv
